# Code of conduct

Treat contributors, users and researchers with respect. Discuss technical work constructively, explain disagreements and make room for different experience levels.

Harassment, threats, discriminatory abuse, unwanted sexual attention and publication of another person's private information are unacceptable. Do not post credentials, private target details or assessment evidence in project spaces. Use authorized, synthetic examples when discussing offensive security behavior.

Maintainers may edit or remove harmful content, close disruptive discussions or restrict participation to protect the community. Contact the repository owner through the contact options on [@Memrov's profile](https://github.com/Memrov) about conduct concerns; avoid posting sensitive details publicly. Report software vulnerabilities through the separate [security reporting process](SECURITY.md).
