# PentCloud tool runtime

Shared native Cloudflare Durable Object execution support for PentCloud’s tool SDKs: serialized commands, pinned-image verification, bounded binary attachments and native streamed Workflow evidence.

Version 0.1.0. See [release and integration instructions](https://github.com/Memrov/PentCloud-tools/blob/main/docs/releases.md). This package does not launch an assessment or deploy an application by itself.
