# Changelog

## 0.1.0

- Package httpx v1.12.0, dnsx v1.3.1, Katana v1.8.0 and Subfinder v2.17.0 in one pinned Linux/amd64 runtime.
- Expose independent tool calls through a native Cloudflare Durable Object and a private Workflow example.
- Preserve upstream JSON, errors, timing and release identity.
- Bound command duration and captured output; serialize commands and stop inactive runtimes.
- Verify upstream downloads and image/adapter compatibility.
